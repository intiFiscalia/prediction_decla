# docs/decisiones/

Registro de decisiones de arquitectura (ADR), un archivo por decisión: `AAAA-MM-DD-titulo.md` con
contexto, opciones consideradas, decisión y consecuencias. Se crea una entrada cada vez que el plan
choca con un hallazgo de los datos reales o se elige entre alternativas técnicas no triviales.

Lectura: cualquier colaborador del proyecto, incluido Claude Code.
