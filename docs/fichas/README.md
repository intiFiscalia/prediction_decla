# docs/fichas/

Fichas técnicas de indicadores, modelos y datos: fórmula, unidad de análisis, numerador,
denominador, limitaciones (indicadores); propósito, datos de entrenamiento, métricas, usos no
permitidos (modelos); cobertura, sesgos conocidos, periodo (datos). Una ficha por indicador o modelo
publicado.

Lectura: cualquier colaborador del proyecto, incluido Claude Code.
