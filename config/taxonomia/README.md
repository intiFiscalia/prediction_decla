# config/taxonomia/

Taxonomía de fenómenos versionada (`version_taxonomia`): código, nombre, definición, criterios de
inclusión/exclusión, ejemplos positivos y negativos, nivel jerárquico, estado. Se congela por versión
(v1.0, v1.1, ...) tras los talleres de validación con analistas (Fase 6 del plan).

Lectura: cualquier colaborador del proyecto, incluido Claude Code.
