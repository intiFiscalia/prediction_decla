# config/

Reglas de negocio versionadas en YAML: contrato de esquema de la fuente (`esquema_fuente.yaml`),
reglas de limpieza y normalización (`reglas_*.yaml`), umbrales de alerta (`umbrales.yaml`), lista de
modelos preentrenados a descargar (`modelos.yaml`), diccionarios (`diccionarios/`) y taxonomía de
fenómenos versionada (`taxonomia/`).

Lectura: cualquier colaborador del proyecto, incluido Claude Code (no contiene datos reales ni
identificadores).
