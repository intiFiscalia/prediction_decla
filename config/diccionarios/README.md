# config/diccionarios/

Gazetteers y listas de expresiones para extracción por reglas: instituciones (DIAN, POLFA, UIAF,
CTI, SIJIN, DIJIN...), mecanismos de lavado, bienes, sinónimos de sector económico (CIIU), variantes
territoriales. Versionados; cada cambio es una entrada nueva, no una edición silenciosa.

Lectura: cualquier colaborador del proyecto, incluido Claude Code.
