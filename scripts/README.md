# scripts/

Utilidades de una sola vez, no parte del pipeline recurrente: `descargar_modelos.py` (modelos
preentrenados → `models/`), `generar_fixtures.py` (datos sintéticos → `tests/fixtures/`),
`preparar_wheelhouse.sh` (dependencias Python → `wheelhouse/`, en una máquina con internet).

Lectura: cualquier colaborador del proyecto, incluido Claude Code.
